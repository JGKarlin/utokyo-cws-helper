# 勤務時間 自動入力

**バージョン 2.4.14** — **東京大学 就労管理システム**向けに、自己申告記録（出勤・退勤）と休憩（勤務外時間数）の入力、および月次の勤務表提出（月次申請）を自動化する Chrome 拡張機能です。

---

## 作成の背景と経緯

2024年11月以降、東京大学において裁量労働制適用教員に対しても、就労管理システムを用いた日々の勤務記録が求められるようになりました。裁量労働制の下であっても事業者が労働時間の状況を把握し、健康確保措置を講じることが制度的に求められているという理解のもと、本学も対応を進めているものです。

しかしながら、実際の運用では日々の入力作業が大きな負担となっています。出勤・退勤時刻の打刻または自己申告、休憩や勤務外時間の入力、休日・深夜の業務命令の有無の確認など、一連の作業を継続的に行う必要があります。学外からの入力にはVPN接続が必要なため、在宅勤務や出張中であっても日々システムにアクセスすることが事実上前提となっています。教育・研究・学生対応の合間にこの作業を組み込むことは想像以上に時間を要し、手続の煩雑さも相まって、業務効率の観点からも大きな負担となっています。過重労働の防止や健康確保を目的とした制度であるはずが、新たに日々の入力・確認という業務が追加されることで、教員側にも事務側にも継続的な作業負担を生じさせており、ある種の逆説的な状況を感じる方も少なくないのではないでしょうか。

本拡張機能は、そのような負担を軽減するために作成しました。自己申告記録（出勤・退勤）の入力に必要な繰り返し作業を自動化し、入力作業に要する時間を削減しながら、正確で適切な記録を維持できるようにすることを目的としています。

**重要：** 本ツールは、実際に勤務した時間の*入力作業*を効率化するためのものです。実際の勤務スケジュールに基づいた時刻のみを入力してください。本拡張機能は、システムの検証や承認プロセスを迂回するものではありません。システムが求める繰り返しのフォーム入力を行うだけです。

## 機能

| 機能 | 説明 |
|------|------|
| **自動モード** | 出勤 8:45〜10:00、退勤 17:00〜19:00 の既定範囲を使用 |
| **手動モード** | 出勤・退勤の時刻範囲を任意に設定可能 |
| **平日のみ対象** | 選択した期間内の平日のみを自動的に対象とする（祝日は除外） |
| **休憩（勤務外時間数）の自動入力** | 各勤務日に出勤・退勤に加えて 45〜60 分の休憩（勤務外時間数）を自動で登録（裁量労働制：1 日 6 時間以上勤務の休憩義務に対応） |
| **勤務表連動** | 本人用実績入力ページの勤務表から勤務日を判定 |
| **月次申請の自動化** | 未提出の月を検出し、確認後に勤務時間の入力と月次申請を自動で実行 |
| **前月承認の待機** | 前月が最終承認されるまで保留し、定期的に自動で再確認・承認後に申請 |
| **毎月自動申請（任意）** | 「毎月自動で申請する」を有効にすると、毎月 前月分を自動で申請（既定オフ） |
| **今月の勤務時間の自動入力（任意）** | 「今月の勤務時間を自動入力する」を有効にすると、今月の出勤日のうち未入力の日を、前月の承認・月次申請の状況とは無関係に自動入力（既定オフ） |
| **当月の全勤務日を対象** | 勤務表から平日を判定し、当月分の未入力日を漏れなく入力（全日休暇取得日は除外） |
| **月次ステータス台帳** | 各月の状態（未提出・申請可能・承認待ち・最終承認など）をサイドパネルに一覧表示 |
| **最近の履歴** | 月次スキャン・勤務時間入力完了・申請結果などの履歴をサイドパネル下部に表示 |
| **バックグラウンド状態の表示** | バックグラウンド実行中の処理内容と、必要な操作（ログインなど）をサイドパネルに表示 |
| **CWS タブの再利用** | バックグラウンド処理で既存の CWS タブを優先的に再利用し、不要なタブ増殖を防止 |
| **CWS 処理の直列化** | 勤務時間入力・月次申請・状態スキャンが同時に走らないよう排他制御（CWS は単一セッション） |
| **ライブ勤務表による完了判定** | 入力完了はセッション状態ではなく、対象月の勤務表を直接読み取って検証 |
| **自動実行トリガー** | ブラウザ起動時・サイドパネル表示時・定期アラームで自動的に処理を開始（CWS ページを開いていなくても、バックグラウンドの隠しタブで実行） |
| **バックグラウンド実行の表示** | バックグラウンド処理中はツールバーアイコンのバッジがスピナー表示になり、実行中であることが分かる |
| **申請可能のバッジ・通知** | 申請できる月があるとツールバーアイコンにバッジを表示し、初回にデスクトップ通知（サイドパネルを開いていなくても気づける） |
| **自動プロンプト** | サイドパネルを開いた際、申請できる月があれば確認ダイアログを自動表示（自動申請オフ時・各月1回。手動ボタンも併用可） |
| **接続状態の表示** | ヘッダーに UTokyo ネットワークへの接続状態（接続／未接続）を表示 |
| **ログイン要求の通知** | バックグラウンド処理中にログイン切れを検出すると通知（クリックでログイン画面を開き、ログイン後に自動再開） |
| **デスクトップ通知** | 申請の完了・保留・失敗・申請可能を通知 |
| **接続時のみ実行** | バックグラウンドの定期処理は CWS に接続できる時のみ実行 |
| **サイドパネル表示** | ツールバーアイコンでサイドパネルを開く。ページ遷移中も進捗を表示し続ける |
| **進捗表示** | 処理中にリアルタイムで進捗と状態を表示 |
| **停止機能** | いつでも処理を停止可能 |

## 必要要件

- **Google Chrome 114 以降**（サイドパネル機能を使用します。Manifest V3 互換の Chromium 系ブラウザ）
- **東京大学アカウント**（UTokyo Account）でシステムにログイン可能
- **就労管理システムのページでアクティブなセッション**があること
- **UTokyo ネットワークへの接続**（学内ネットワークまたは VPN）

本拡張機能は、東京大学就労管理システムのドメイン（`ut-ppsweb.adm.u-tokyo.ac.jp`）でのみ動作します。学外から利用する場合は VPN 接続が必要です。接続状態はヘッダーの「接続／未接続」表示で確認できます。

## インストール（開発者モード）

本拡張機能は Chrome の開発者モードで読み込む必要があります。

### 1. ダウンロード

- **[Releases ページ](https://github.com/JGKarlin/utokyo-cws-helper/releases)** から最新版の **ZIP ファイル** をダウンロードし、解凍してください。
- または [リポジトリ](https://github.com/JGKarlin/utokyo-cws-helper) の **Code** → **Download ZIP** をクリックしてダウンロードし、解凍してください。

### 2. Chrome に読み込む

1. Chrome の拡張機能管理ページを開きます。
   - メニュー（⋮）→ **拡張機能** → **拡張機能を管理**
   - またはアドレスバーに `chrome://extensions` と入力して Enter
2. 右上の **開発者モード** のトグルをオンにします。
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、解凍した拡張機能のフォルダ（`manifest.json` が含まれるフォルダ）を選択します。

これでインストール完了です。必要に応じてツールバーにピン留めしてください。

## 使い方

### 基本的な流れ

1. ブラウザで就労管理システムに**ログイン**します。
2. Chrome ツールバーの拡張機能アイコンをクリックして**サイドパネルを開きます**。サイドパネルは画面の横に固定表示され、ページの自動遷移中も開いたまま進捗を表示し続けます。
3. 設定を**構成**します（下記参照）。
4. 出退勤を入力する場合は **「入力開始」**、月次申請を行う場合は **月次申請の各ボタン** をクリックします。

本拡張機能は、就労管理システムのページ（例：メインメニューや `ut-ppsweb.adm.u-tokyo.ac.jp` 上の任意のページ）を**開いている状態**で使用してください。

---

### 設定項目

#### 出退勤設定

- **自動：** 出勤 8:45〜10:00、退勤 17:00〜19:00 の既定範囲を使用します。
- **手動：** 出勤・退勤の時刻範囲を任意に設定できます。各日の時刻は設定した範囲内でランダムに選択されます。
- **休憩（勤務外時間数）：** いずれのモードでも、各勤務日に 45〜60 分の休憩（勤務外時間数）を自動で登録します。裁量労働制では 1 日の勤務が 6 時間以上の場合に 45 分以上の休憩が必要なため、出勤・退勤と合わせて自動的に入力されます（就労申請メニューの「【裁量労働制】勤務外時間数」を使用）。

#### 対象期間

- **開始日：** 対象期間の最初の日
- **終了日：** 対象期間の最後の日
- **平日のみ対象：** 平日のみが処理対象となり、土日は除外されます。

---

### 実行中

- 拡張機能がシステム内を自動的にナビゲートします。
- サイドパネルに進捗（ステータステキストとプログレスバー）が表示されます。サイドパネルはページ遷移中も開いたままなので、処理の様子をそのまま確認できます。
- いつでも **停止** をクリックして処理を中断できます。
- セッションが切れた場合やエラーが発生した場合は、再度ログインしてやり直す必要がある場合があります。

## 月次申請（月次の勤務表提出）

出退勤の入力に加えて、月次の勤務表提出（月次申請）も自動化できます。

### 仕組み

1. サイドパネルを開くと、未提出の月（前月など）を検出し、「**○年○月分を申請**」ボタンを表示します。
2. ボタンを押すと、確認のうえで自動的に次を行います。
   - 対象月の勤務表を開く
   - 未入力の平日の勤務時間（出勤・退勤・休憩）を自動入力（祝日は本人用実績入力の平日判定により除外）
   - 月次申請を送信
3. 月次申請には**前月の最終承認**が必要です。前月が未承認の場合は申請を保留し、接続できる時に定期的（数時間ごと）に自動で再確認します。前月が承認され次第、自動で申請します。

### 毎月自動で申請する（任意・既定オフ）

- サイドパネルの「**毎月自動で申請する**」をオンにすると、毎月、前月分の月次申請を自動で行います（有効化時に確認ダイアログが表示されます）。
- オフのままなら自動申請は行われず、上記のボタンから手動で実行できます。
- オンにすると、手動入力専用の設定（対象期間・入力開始）は非表示になり、画面がすっきりします。オフに戻すと再表示されます。
- **出退勤設定（時刻範囲）は表示されたまま** で、ここで設定した出退勤時刻が **自動の月次申請でも使用** されます（既定は 出勤 8:45〜10:00／退勤 17:00〜19:00。手動で変更可）。
- バックグラウンドの定期確認は、CWS に接続できる（学内ネットワークまたは VPN）場合のみ実行されます。未接続時は何もせず、接続できる時に再試行します。

### 通知

- 申請の **完了**・**保留**（前月の承認待ち）・**失敗**・**申請可能**（申請できる月の検出）・**ログイン要求**（バックグラウンド処理中のログイン切れ）を、デスクトップ通知でお知らせします（保留・申請可能の通知は初回のみ）。
- 申請が完了すると、サイドパネルのボタンが「**○年○月分の勤務実績を提出しました（承認待ち）**」の表示に変わり、ツールバーのバッジは消えます。

> **重要：** 月次申請は **実際に送信され、取り消せません**。確認ダイアログで対象月を確認のうえ実行してください。本拡張機能は入力作業を自動化するものであり、実際に勤務した時間のみを入力してください。

## 今月の勤務時間の自動入力（任意・既定オフ）

月次申請とは**独立**して、今月分の勤務時間の入力だけを自動化できます。前月が未承認で月次申請が保留中でも、今月の日々の入力はそれに**妨げられずに実行**されます。

- サイドパネルの「**今月の勤務時間を自動入力する**」をオンにすると、今月の出勤日のうち**未入力の日**を、出退勤設定の時刻で自動入力します（有効化時に確認ダイアログが表示されます）。
- **当月の全勤務日**を勤務表から判定し、未入力の平日を漏れなく対象とします（`年休（日） 年次有給休暇 全日` などの全日休暇取得日は除外）。
- **既存の記録は上書きしません。** 勤務表を毎回読み取り、記録のない平日のみを対象とします。入力完了は**ライブ勤務表**で検証し、「最近の履歴」に記録されます。
- **自動で開始します。** ブラウザ起動時・サイドパネルを開いた時・定期アラーム（数時間ごと、初回は約1分後）に、CWS に接続できる場合のみ、バックグラウンドの隠しタブで実行します。CWS のページを自分で開いておく必要はありません。
- バックグラウンド実行中は、ツールバーアイコンのバッジが**スピナー表示**になり、サイドパネルにも実行中の状態が表示されます。
- 対象月への遷移は**リンクテキスト方式**で行うため、システム側の URL トークン（`@FN`）やレイアウト変更の影響を受けにくくなっています。
- CWS への同時アクセスを避けるため、勤務時間入力・月次申請・状態スキャンは**直列化**されます。既存の CWS タブがあれば**再利用**します。

## 月次ステータスと履歴

サイドパネル上部の「勤務表の提出（月次申請）」カードに、各月の現在状態を表示します。

- **月次ステータス台帳：** 未提出・申請可能・承認待ち・最終承認・差戻など、月ごとの状態を一覧表示します。申請可能な月はボタンから手動申請できます。
- **最近の履歴：** パネル下部に、月次スキャン・勤務時間入力完了・申請結果などの履歴を時系列で表示します（最大件数を超えた古い履歴は自動的に整理されます）。
- **ライブ状態の優先：** キャッシュよりも、CWS 上の勤務表・処理状況から読み取った最新情報を優先して表示します。
- **確認済み台帳（再確認しません）：** 最終承認は CWS 上で覆ることがない終了状態です。いちど最終承認を確認した月は「確認済み」として台帳に記録し、チェックマーク付きの緑色で表示します。以降その月を再度確認することはありません。過去月をさかのぼる確認は、確認済みの月に達した時点で停止するため、ブラウザを起動するたびに 5 月・6 月・7 月…… を開き直すことがなくなります。
- **今月・前月の表示：** 承認待ちの月には位置がわかる見出しを付けます（例：`2026年9月分（今月・進行中）`、`2026年8月分（前月・承認待ち）`）。それより古い月は月名のみで表示します。

## 技術仕様

- **拡張機能バージョン：** 2.5.0
- **Manifest バージョン：** 3
- **権限：** `activeTab`、`scripting`、`storage`、`tabs`、`alarms`、`notifications`、`sidePanel`、および `ut-ppsweb.adm.u-tokyo.ac.jp` へのホストアクセス
- **UI：** サイドパネル（ツールバーアイコンで開く。`popup.html` / `popup.js` / `status-model.js`）
- **コンテンツスクリプト：** `navigation-model.js`、`term-hours-model.js`、`status-model.js`、`content.js` — 就労管理システムのページでナビゲーションとフォーム入力を行います。
- **サービスワーカー：** `background.js`（`status-model.js` を共有）— ストレージアクセス、サイドパネル起動、接続確認、月次申請の定期再試行・自動申請、今月分の勤務時間自動入力、CWS タブ再利用・直列化、ツールバーバッジ（実行中スピナー）、デスクトップ通知を担当します。起動時・パネル表示時・アラームで処理を開始します。
